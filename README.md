KonquerXi Web (Next.js) — Scaffold

This is a minimal Next.js 14 app skeleton with BD routes. It is a scaffold only; install dependencies locally to run.

Quick start
- cd frontend/web
- npm install
- npm run dev

Routes
- /            — landing
- /bd          — BD dashboard placeholder
- /api/health  — returns { ok: true }

Config
- Set NEXT_PUBLIC_API_BASE to point to UI Adapter or BD API.
